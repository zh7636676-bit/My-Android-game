# Skardu Mountain Racing - Complete Android Studio Project

## How to Build the Signed Android APK:
1. Open this unzipped folder in **Android Studio**.
2. Wait for Gradle sync to complete.
3. Click **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
4. Your installable APK will be ready at:
   `app/build/outputs/apk/debug/app-debug.apk` (or release APK).
5. Transfer to any Android phone and install!
